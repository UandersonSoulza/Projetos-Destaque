# Projetos em Destaque

Repositório com os projetos que melhor representam minha evolução no desenvolvimento de software: aplicações web e desktop construídas com Java, Python, Spring Boot e Flask, cobrindo desde interface gráfica e persistência de dados até autenticação e arquitetura em camadas.

Cada pasta abaixo é um projeto independente, com seu próprio README detalhado (como rodar, tecnologias, funcionalidades).

| Projeto | Stack principal | Destaque |
|---|---|---|
| [`sistema-consultas-medicas`](./sistema-consultas-medicas) | Python, Flask, MySQL | Aplicação web completa (CRUD + autenticação) para gestão de clínica: pacientes, médicos, consultas e exames |
| [`controle-estoque-spring`](./controle-estoque-spring) | Java, Spring Boot, Thymeleaf, MySQL | Sistema de controle de estoque com categorias, movimentações e autenticação, seguindo arquitetura em camadas (Controller/Service/Repository) |
| [`gerenciador-produtos-desktop`](./gerenciador-produtos-desktop) | Java, Swing | Aplicação desktop de cadastro de produtos com login, seguindo o padrão MVC com camada DAO |

## Sobre

Estes projetos foram desenvolvidos ao longo da minha formação técnica (SENAI), aplicando conceitos de orientação a objetos, banco de dados relacional, arquitetura em camadas (MVC) e desenvolvimento web back-end.
